# 规则示例

一条规则同时携带三层，运行时按字段决定它落到哪：

| 字段 | 层 | 强制方式 | 代价 |
|---|---|---|---|
| `denyTools` | **T3** | 工具根本不出现在模型看到的定义里 | 零 |
| `requiredFields` | **T2** | 结果缺字段就退回让它重写，原文回给模型 | 一次重写 |
| 正文 | **T1** | 注入末尾约束块 —— 只是提示，不是强制 | **每一轮**都占约束块 token |

两条原则由校验强制，不靠自觉：

1. **T1 必须配 T2 或 T3。** 只有正文的规则会被**拒绝** —— 那等于
   「prompt 里写满禁止但模型照犯」，而且它会出现在规则清单里、看起来系统在管，
   实际什么都没管。**看起来有约束比没有约束更糟。**
2. **能用 T3 表达的绝不写成 T1。** T3 零成本且不可违反。

用法：把 `.md` 复制到项目根的 `rules/` 下。`nucleus rules` 会列出来。
